# 变量

在转换条件或动作中使用的每个名称都是项目的一个**变量**。声明变量会为它指定类型和方向，使 GrafcetMaker 能够检查您的表达式，并使仿真器提供合适的控件。

## 变量的种类 {#kinds-of-variables}

- **方向**：**输入**来自过程（传感器、按钮），只能读取；**输出**驱动过程（电机、灯）；**内部**变量是存储器或计数器。
- **类型**：`BOOL`（真 / 假）、`INT`（整数）、`REAL`（小数）或 `TIME`（时长，例如 `500ms`、`3s`）。
- **初始值**：仿真开始时的值（为空时为 FALSE 或 0）。
- **地址**和**注释**：自由文本，例如 PLC 地址 `%I0.0` 以及该信号的含义。

名称不区分大小写，使用字母、数字和 `_`，不能是保留字（`AND`、`OR`、`NOT`、`RE`、`FE`、`TRUE`、`FALSE`、`MOD`、`INIT`），也不能看起来像步变量（`X12`）。

## 创建变量 {#creating-variables}

- 输入表达式时，新名称会在您确认时声明：在转换条件中为输入，在动作中为输出。这是最快的方法。
- 在变量列表或变量表中使用**添加变量**。
- 从 Excel 或 CSV **导入**列表（见下文）。

## 变量表 {#the-variable-table}

右下角的**变量**按钮会在窗口右侧打开变量：一个紧凑的列表（搜索、筛选标签、按方向分组；单击某个变量可编辑它并查看它的使用位置）。拖动面板的左边缘将其加宽，它就会变成变量表，每个字段各占一列。可直接编辑任何单元格（<kbd>Enter</kbd> 或离开单元格即应用，<kbd>Esc</kbd> 还原），单击列标题可排序，可按文本、方向和类型筛选。即使有数千个变量，变量表也能保持流畅。

**使用**列统计使用每个变量的表达式数量；未使用的变量以橙色显示 `0`。单击该数字可在属性卡片中打开该变量：编辑它的所有字段并查看**使用位置**；单击某处使用可跳转到图表上对应的转换条件或动作。

**⋯** 旁边的扫帚按钮可一次移除所有未使用的变量（其徽标显示数量）：即没有任何转换条件、动作或条件使用，也没有任何场景驱动的变量。这只需一步即可撤销（<kbd>Ctrl+Z</kbd>）。它也在命令面板中：**移除未使用的变量**。

在手机上，变量面板改为一个紧凑的列表：搜索、筛选标签（**输入**、**输出**、**内部**）、按方向分组，轻点即可打开某个变量及其使用位置。

## 重命名 {#renaming}

重命名变量会更新所有 grafcet 中使用它的每个转换条件、动作和条件，并作为一次可撤销的更改。

## Excel 和 CSV {#excel-and-csv}

使用变量列表或变量表的 **⋯** 菜单，或 **文件 › 变量**：

- **将变量导出为 Excel** 会写入一个 `.xlsx` 工作簿，带有冻结的表头、筛选器以及类型和方向的下拉列表。
- **将变量导出为 CSV** 会为其他工具写入一个文本文件。
- **导入变量** 读取 `.xlsx` 或 `.csv` 文件（也可以将其拖放到窗口上）。

列为 `name`、`type`、`direction`、`initial`、`address` 和 `comment`（顺序任意；只有 `name` 和 `type` 是必需的）。在任何内容更改之前，您会看到将有多少个变量被添加、更新或拒绝，以及每个被拒绝的行的原因。变量按名称匹配；文件中没有的变量将保留。导入是一次可撤销的更改。

> **提示：**要在 Excel 中准备列表，请先导出：您会得到正确的列和下拉列表，然后填写各行，再将文件导入回来。
