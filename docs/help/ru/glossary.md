# Глоссарий

Стандартные термины GRAFCET (IEC 60848) в том виде, в каком они используются в GrafcetMaker.

| Термин                               | Значение                                                                                                          |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| **Активный шаг**                     | Шаг, входящий в текущую ситуацию; при моделировании несёт метку.                                                  |
| **Ветвление И**                      | Двойная линия после перехода, одновременно активирующего несколько шагов (параллельные ветви).                    |
| **Ветвление ИЛИ**                    | Одинарная линия после шага, за которым следуют несколько переходов; выбирается один путь.                         |
| **Действие**                         | То, что система делает в связи с шагом; изображается в прямоугольнике справа от шага.                             |
| **Запоминаемое действие**            | Действие, выполняемое один раз — при активации, при деактивации или по событию, — результат которого сохраняется. |
| **Команда принудительной установки** | Действие, задающее ситуацию другому частичному графсету, например `G2{8}`.                                        |
| **Макрошаг**                         | Шаг, заменяющий развёртку, нарисованную на отдельном листе.                                                       |
| **Начальный шаг**                    | Шаг, активный при запуске; изображается двойным квадратом.                                                        |
| **Неустойчивый шаг**                 | Шаг, активированный и деактивированный в ходе одного поиска устойчивости.                                         |
| **Непрерывное действие**             | Выход истинен, пока его шаг активен (и его условие истинно).                                                      |
| **Охватывающий шаг**                 | Шаг, содержащий вложенный графсет, который работает, только пока шаг активен.                                     |
| **Переменная шага**                  | `Xn`: истинна, пока шаг n активен.                                                                                |
| **Переход**                          | Черта между шагами; графсет эволюционирует через срабатывание переходов.                                          |
| **Переход-источник / переход-сток**  | Переход без шага над ним / под ним.                                                                               |
| **Переход, готовый к срабатыванию**  | Разрешён, и его условие перехода истинно: переход сработает.                                                      |
| **Поиск устойчивости**               | Повторное применение правил эволюции после изменения входа, пока ни один переход не сможет сработать.             |
| **Разрешённый переход**              | Переход, все предшествующие шаги которого активны.                                                                |
| **Развёртка**                        | Графсет, нарисованный для макрошага, от его входного шага E до выходного шага S.                                  |
| **Ситуация**                         | Множество активных шагов в данный момент.                                                                         |
| **Слияние И**                        | Двойная линия, на которой заканчиваются параллельные ветви; следующий переход ждёт их все.                        |
| **Слияние ИЛИ**                      | Одинарная линия, на которой снова соединяются альтернативные ветви.                                               |
| **Событие**                          | Фронт или другое мгновенное условие, запускающее запоминаемое действие по событию.                                |
| **Срабатывание (перехода)**          | Преодоление перехода: активировать шаги под ним, деактивировать шаги над ним.                                     |
| **Таймер**                           | `t/c`: истинен через время t после того, как условие c стало истинным, например `5s/X2`.                          |
| **Условие перехода**                 | Условие, записанное рядом с переходом.                                                                            |
| **Условие присваивания**             | Условие непрерывного действия: выход истинен, только пока выполняется и это условие.                              |
| **Фронт**                            | Мгновенное изменение сигнала: передний фронт ↑a (ложь → истина), задний фронт ↓a (истина → ложь).                 |
| **Частичный графсет**                | Один из графсетов проекта; все они работают вместе.                                                               |
| **Шаг**                              | Устойчивое состояние системы; изображается пронумерованным квадратом.                                             |
