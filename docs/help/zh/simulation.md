# 仿真

仿真器严格按照 IEC 60848 规则运行您的 grafcet，因此您可以在它进入 PLC 之前对它进行测试。

## 开始和停止 {#start-and-stop}

按 <kbd>F5</kbd>（或 **仿真 › 开始仿真**）。图表被锁定，仿真控制替换顶部的工具，左侧出现**仿真**面板（用它的箭头折叠可看到更多图表），时钟开始运行。<kbd>Shift+F5</kbd> 停止并返回编辑。

## 更改输入 {#change-inputs}

**仿真**面板列出各个输入：

- **BOOL** 输入有一个开关，以及一个用于点动的**按住**按钮（类似按钮开关；使用键盘时，在它上面按住 <kbd>Space</kbd>）。
- **INT**、**REAL** 和 **TIME** 输入有一个值字段。

您也可以**在图表上 BOOL 输入所写的位置单击它**（转换条件或条件中，用手指则轻点）：它会打开或关闭。只要某个输入发生变化，grafcet 就会演变。

仿真期间，写在转换条件或条件中的每个 **INT**、**REAL** 或 **TIME** 变量都会在其名称上方的小框中显示当前值，存储型动作会在其方框下方显示它所写入变量的值。**单击某个值**（或轻点它）可输入新值，然后按 <kbd>Enter</kbd>（<kbd>Escape</kbd> 取消）。这对输入有效，对内部变量和输出也有效，例如可以试一试接近其上限的计数器。

**指向一个转换**（或轻点它）可查看它在等待什么：必须先激活的步，或其转换条件中仍为假的项，以及 `10s/X0` 这类定时器的剩余时间。`↑start` 这样的边沿总会列出：它只在其输入发生变化的那一刻为真。

## 时间 {#time}

仿真器中的时间是虚拟的、确定性的。

- <kbd>F5</kbd> 暂停时钟并再次运行。定时器（`5s/X2`）只在时钟运行时前进。
- 速度从 ×0.25 到 ×10。**快速**直接从一个定时器到期跳到下一个。
- <kbd>F10</kbd> 跳到下一个定时器到期并运行该周期。
- **⟲** 从初始情况重新开始。

仿真栏显示时间、周期编号以及下一个定时器何时到期。默认速度在 **设置 › 仿真** 中。

## 您在图表上看到的内容 {#what-you-see-on-the-diagram}

- **激活的步**被填充并带有一个标记圆点，下方显示它们已激活的时长。
- **已使能的转换**带有 ▶ 标记；转换实现时会闪烁。
- **为真的信号**在转换条件和动作条件中显示为绿色、粗体并带下划线：处于开状态的变量、激活的步 `Xn`、成立的比较。不是绿色的部分就是转换仍在等待的内容。在 NOT 上划线下，颜色显示的是信号本身：在 `/a` 中，当 `a` 为开时 `a` 为绿色。
- 正在执行的**连续动作**显示 ✓；**存储型动作**显示其变量的当前值。

## 演变日志 {#evolution-log}

仿真面板的日志（已折叠：单击**演变日志**打开）列出每个周期、触发它的原因以及寻求稳定的每次迭代：实现的转换、激活和停用的步。瞬态演变（被越过而未停留的步）在这里可以看到。单击某个周期可查看图表在那一刻的样子。

## 观察多个 grafcet {#watching-several-grafcets}

在分屏（<kbd>Ctrl+\</kbd>）中，两个窗格都实时显示仿真：可以并排观察生产 grafcet 和它的安全 grafcet，或者一个宏步和它的展开。

## 时序图 {#chronogram}

**时序图**面板（其按钮在右下角）绘制每个变量以及打开的 grafcet 中各步随时间的变化。在其中单击或拖动可回到过去的时间：图表会随之变化。**返回实时**回到当前。

## 场景 {#scenarios}

要准确地重复一次测试，请将它录制下来：

1. 单击**录制**：仿真重新开始，并记录每次输入更改及其时间。
2. 进行测试，然后停止录制并为场景命名。场景保存在项目中。
3. **回放**会重新开始仿真并回放该场景。

## 当 grafcet 始终无法稳定时 {#when-the-grafcet-never-settles}

如果转换不断地相互实现（例如一个每个转换条件都为真的回路），演变就永远不会稳定。仿真器在 1000 次迭代后停止，并在“问题”中报告**瞬态循环**。请添加一个条件（通常是边沿 `↑a`），使该回路不能无限运行。请参阅[故障排除](troubleshooting.md)。
