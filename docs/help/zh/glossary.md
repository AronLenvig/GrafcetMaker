# 术语表

GrafcetMaker 中使用的 GRAFCET 标准术语（IEC 60848）。

| 术语                   | 含义                                                           |
| ---------------------- | -------------------------------------------------------------- |
| **动作**               | 系统与某个步相关联所做的事情；画在步右侧的矩形中。             |
| **激活步**             | 属于当前情况的步；在仿真中带有一个标记。                       |
| **并行汇合**           | 并行分支结束处的双线；下一个转换会等待所有分支。               |
| **并行分支**           | 转换之后的双线，同时激活多个步（并行分支）。                   |
| **赋值条件**           | 连续动作的条件：只有该条件也成立时，输出才为真。               |
| **实现（转换）**       | 越过转换：激活下方的步，停用上方的步。                         |
| **可实现**             | 已使能且转换条件为真：该转换将会实现。                         |
| **连续动作**           | 在其步激活期间（且其条件为真时）为真的输出。                   |
| **边沿**               | 信号的瞬时变化：上升沿 ↑a（假 → 真），下降沿 ↓a（真 → 假）。   |
| **已使能的转换**       | 上游步全部激活的转换。                                         |
| **封装步**             | 包含一个被封装的 grafcet 的步，该 grafcet 仅在此步激活时运行。 |
| **事件**               | 触发事件型存储动作的边沿或其他瞬时条件。                       |
| **展开**               | 为宏步绘制的 grafcet，从其入口步 E 到出口步 S。                |
| **强制命令**           | 将某个情况强加给另一个局部 grafcet 的动作，例如 `G2{8}`。      |
| **初始步**             | 启动时激活的步；画成双线方框。                                 |
| **宏步**               | 代表一个绘制在单独图页上的展开的步。                           |
| **选择汇合**           | 选择分支重新汇合处的单线。                                     |
| **选择分支**           | 后面跟着多个转换的步之后的单线；只选择一条路径。               |
| **局部 grafcet**       | 项目中的一个 grafcet；所有局部 grafcet 同时运行。              |
| **转换条件**           | 写在转换旁边的条件。                                           |
| **寻求稳定**           | 输入变化后反复应用演变规则，直到没有转换可以实现为止。         |
| **情况**               | 某一时刻所有激活步的集合。                                     |
| **源转换 / 阱转换**    | 上方 / 下方没有步的转换。                                      |
| **步**                 | 系统的一种稳定状况；画成带编号的方框。                         |
| **步变量**             | `Xn`：步 n 激活期间为真。                                      |
| **存储型动作**         | 执行一次（在激活时、停用时或事件发生时）且其效果会保持的动作。 |
| **定时器**             | `t/c`：在条件 c 变为真之后经过时间 t 时为真，例如 `5s/X2`。    |
| **不稳定步（瞬态步）** | 在一次寻求稳定的过程中被激活又被停用的步。                     |
| **转换**               | 步之间的横杠；grafcet 通过实现转换而演变。                     |
