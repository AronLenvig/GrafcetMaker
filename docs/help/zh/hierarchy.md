# 宏步、封装步和强制

大型应用拆分开来更易于阅读。GRAFCET 提供了三种工具，GrafcetMaker 中都可以使用。

## 多个局部 grafcet {#several-partial-grafcets}

一个项目可以包含多个**局部 grafcet**，每个对应窗口底部的一个标签页，例如 _G1_ 用于生产循环，_G2_ 用于安全逻辑。它们全部同时运行，并可通过步变量相互观察（G2 的步 21 激活期间，G1 中的 `X21` 为真）。

- 单击标签页旁边的 **+** 可添加一个。它的步编号从下一个空闲的十位数开始（20、30……），因此 `Xn` 引用不会产生歧义。
- 双击标签页（或在其上按 <kbd>F2</kbd>）可重命名；将其向侧面拖动可改变顺序；在其上按 <kbd>Del</kbd> 可删除。<kbd>Ctrl</kbd>+单击或 <kbd>Shift</kbd>+单击可选择多个标签页以一起删除。右键单击标签页可查看更多操作。标签页很多时，可用鼠标滚轮或 ‹ › 按钮滚动。

## 宏步 {#macro-steps}

**宏步**代表绘制在单独图页上的详细序列，即它的**展开**。它画成一个带两条水平线的步。

<!-- figure: macro | 主序列中的一个宏步 -->

1. 选中一个步，在属性面板中将其**类型**设为_宏步_（或使用 **编辑 › 设为宏步（带展开）**）。
2. 一个新标签页会打开展开：由一个转换连接的入口步 **E** 和出口步 **S**。在它们之间绘制详细序列。
3. 双击宏步（或按 <kbd>Alt+↓</kbd>）可打开其展开；<kbd>Alt+↑</kbd> 返回到宏步。

宏步被激活时，其入口步变为激活；只有当出口步激活时，宏步之后的转换才被使能。只要其展开中有任何一个步激活，宏步就算作激活。

## 封装步 {#enclosing-steps}

**封装步**包含一个完整的 grafcet，即**被封装的 grafcet**，它仅在封装步激活时运行。可将其用于运行模式：_自动_、_手动_、_调整_。它画成一个带两条竖线的步。

1. 将步的**类型**设为_封装步_（或使用 **编辑 › 设为封装步（带被封装的 grafcet）**）。
2. 一个新标签页包含被封装的 grafcet。其中标有 `*` 的步在封装步被激活时变为激活。
3. 离开封装步时，被封装的 grafcet 的每个步都会被停用。

展开和被封装的 grafcet 的标签页带有 **M** 或 **E** 徽标。

## 强制命令 {#forcing-orders}

**强制命令**是一种动作，在其步激活期间将某个情况强加给另一个局部 grafcet。在此期间，被强制的 grafcet 不会演变。

| 命令       | 对 G2 的作用         |
| ---------- | -------------------- |
| `G2{8}`    | 只有步 8 激活        |
| `G2{8, 9}` | 只有步 8 和步 9 激活 |
| `G2{*}`    | 冻结在当前情况       |
| `G2{}`     | 没有任何步激活       |
| `G2{INIT}` | 恢复到初始情况       |

强制是描述急停和模式切换的标准方法：例如，安全 grafcet 将生产 grafcet 强制到其初始情况。grafcet 不能强制自身，两个 grafcet 也不能相互强制。

## 检查 {#checks}

GrafcetMaker 会检查每个宏步和封装步是否都有自己的、类型正确的子 grafcet，展开是否恰好有一个入口步和一个出口步，以及强制命令是否指向存在的 grafcet 和步。
