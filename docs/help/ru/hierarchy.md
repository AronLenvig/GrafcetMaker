# Макрошаги, охватывающие шаги и принудительная установка

Большие приложения легче читать, если их разделить на части. GRAFCET предлагает для этого три
средства, и все они доступны в GrafcetMaker.

## Несколько частичных графсетов {#several-partial-grafcets}

Проект может содержать несколько **частичных графсетов**, по одной вкладке на каждый внизу окна,
например _G1_ для производственного цикла и _G2_ для логики безопасности. Все они работают
одновременно и могут следить друг за другом через переменные шагов (`X21` в G1 истинна, пока шаг 21
графсета G2 активен).

- Щёлкните **+** рядом с вкладками, чтобы добавить графсет. Номера его шагов начинаются со
  следующего свободного десятка (20, 30…), чтобы ссылки `Xn` оставались однозначными.
- Дважды щёлкните вкладку (или нажмите на ней <kbd>F2</kbd>), чтобы переименовать её; перетащите
  её в сторону, чтобы изменить порядок; нажмите на ней <kbd>Del</kbd>, чтобы удалить её.
  <kbd>Ctrl</kbd>+щелчок или <kbd>Shift</kbd>+щелчок выбирает несколько вкладок, чтобы удалить их
  вместе. Правый щелчок по вкладке открывает другие команды. Множество вкладок прокручивается
  колёсиком мыши или кнопками ‹ ›.

## Макрошаги {#macro-steps}

**Макрошаг** заменяет подробную последовательность, нарисованную на отдельном листе, — его
**развёртку**. Он изображается как шаг с двумя горизонтальными линиями.

<!-- figure: macro | Макрошаг в основной последовательности -->

1. Выделите шаг и задайте ему **Вид** _Макрошаг_ на панели «Свойства» (или
   **Правка › Сделать макрошагом**).
2. Открывается новая вкладка с развёрткой: входной шаг **E** и выходной шаг **S**, связанные
   переходом. Нарисуйте между ними подробную последовательность.
3. Дважды щёлкните макрошаг (или нажмите <kbd>Alt+↓</kbd>), чтобы открыть его развёртку;
   <kbd>Alt+↑</kbd> возвращает к макрошагу.

Когда макрошаг активируется, его входной шаг становится активным; переход после макрошага
разрешён, только когда активен выходной шаг. Макрошаг считается активным, пока активен любой шаг его
развёртки.

## Охватывающие шаги {#enclosing-steps}

**Охватывающий шаг** содержит целый графсет — **вложенный графсет**, — который работает, только пока
охватывающий шаг активен. Используйте его для режимов: _автоматический_, _ручной_, _наладка_. Он
изображается как шаг с двумя вертикальными линиями.

1. Задайте шагу **Вид** _Охватывающий шаг_ (или **Правка › Сделать охватывающим шагом**).
2. Новая вкладка содержит вложенный графсет. Отмеченные там знаком `*` шаги становятся активными
   при активации охватывающего шага.
3. Когда охватывающий шаг покидается, все шаги вложенного графсета деактивируются.

Вкладки развёрток и вложенных графсетов несут значок **M** или **E**.

## Команды принудительной установки {#forcing-orders}

**Команда принудительной установки** — это действие, которое задаёт ситуацию другому частичному
графсету, пока её шаг активен. Принудительно установленный графсет в это время не эволюционирует.

| Команда    | Действие на G2                     |
| ---------- | ---------------------------------- |
| `G2{8}`    | активен только шаг 8               |
| `G2{8, 9}` | активны только шаги 8 и 9          |
| `G2{*}`    | заморожен в своей текущей ситуации |
| `G2{}`     | ни один шаг не активен             |
| `G2{INIT}` | возврат в начальную ситуацию       |

Принудительная установка — стандартный способ описать аварийные остановы и смену режимов: например,
графсет безопасности принудительно переводит производственный графсет в его начальную ситуацию.
Графсет не может принудительно устанавливать сам себя, и два графсета не могут принудительно
устанавливать друг друга.

## Проверки {#checks}

GrafcetMaker проверяет, что у каждого макрошага и охватывающего шага есть свой подграфсет нужного
вида, что у развёрток один входной и один выходной шаг и что команды принудительной установки
указывают на существующие графсеты и шаги.
