# 入门

在本教程中，您将绘制一个小型储罐的控制：操作员按下 **start** 时，泵向储罐注水直到 **full**（满），然后阀门将其排空直到 **empty**（空），系统再等待下一次启动。整个过程大约需要十分钟。

<!-- figure: sequence | 您将绘制的 grafcet -->

## 1. 熟悉界面 {#1-find-your-way-around}

- **画布**占满整个窗口：您在这里绘图。其他所有内容都浮在画布之上，在您指向它们之前略微淡化，从而让图表保持在最前面。
- **顶部**：左侧是主菜单 ☰ 和项目名称；中间是工具（选择、平移、放置步、转换、注释或动作），最后是 ▶ **仿真**；右侧是问题计数器、**导出**和分享。
- **工具下方**：提示显示您此刻可以执行的操作。在学习本教程时请留意它们。
- **左侧**：选中某个元素时，其**属性**会显示在一张卡片中。
- **底部**：左侧是缩放、撤销和重做；中间是每个 grafcet 一个的标签页；右侧是**变量**、**问题**、**时序图**和**大纲**按钮，每个按钮都会在窗口右侧打开对应的面板，然后是帮助、反馈以及用于切换语言的旗帜。

新项目已经包含 grafcet **G1** 和步 **0**。它的双线方框表示它是一个**初始步**：系统启动时它处于激活状态。

## 2. 添加第一个转换和步 {#2-add-the-first-transition-and-step}

1. 单击步 **0** 以将其选中。
2. 按 <kbd>Enter</kbd>。下方会出现一个转换和步 **1**，您可以直接在转换所在的位置输入它的**转换条件**，即继续前进的条件。
3. 输入 `start` 并按 <kbd>Enter</kbd>。

`start` 尚未声明：在您输入时，编辑器会提示 **新变量 start：BOOL 输入**，按 <kbd>Enter</kbd> 即可将其添加到变量列表中（会有一条消息告诉您）。

## 3. 添加动作 {#3-add-an-action}

步 1 仍处于选中状态。按 <kbd>A</kbd>，输入 `Pump` 并按 <kbd>Enter</kbd>：`Pump` 被创建为 BOOL 输出。现在只要步 1 激活，泵就会运行。

## 4. 继续序列 {#4-continue-the-sequence}

1. 再次按 <kbd>Enter</kbd>：在步 1 之后添加转换和步 **2**。输入 `full` 作为转换条件，并创建该输入。
2. 按 <kbd>A</kbd> 并添加动作 `Valve`（创建该输出）。

> **提示：**更喜欢用鼠标？选中的步会以虚线**幽灵**形式显示 <kbd>Enter</kbd> 和 <kbd>A</kbd> 将要添加的内容；单击其中一个即可添加（请参阅[编辑图表](editing.md#ghosts)）。

## 5. 闭合回路 {#5-close-the-loop}

储罐排空后，循环必须返回到步 0。

1. 选中步 **2** 后，按 <kbd>L</kbd>。提示显示 **单击要返回到的步**。
2. 单击步 **0**。步 2 下方会添加一个转换，并有一条连线向上通往步 0；由于它向上走，因此带有箭头。
3. 输入 `empty` 作为其转换条件，按 <kbd>Enter</kbd> 并创建该输入。

现在您的图表与本页顶部的图一致了。

## 6. 检查 {#6-check-it}

查看右上角的计数器：红色圆圈统计**错误**，橙色三角形统计**警告**。单击它们可打开**问题**列表。每个问题都会说明哪里出错以及出错位置；单击问题可跳转到对应元素，如果有修复按钮，可以使用它。正确的图表没有错误。每条消息的含义请参阅[故障排除](troubleshooting.md)。

## 7. 仿真 {#7-simulate}

1. 按 <kbd>F5</kbd>。图表被锁定，左侧出现**仿真**面板。步 0 带有一个标记：它处于激活状态。
2. 在面板中打开 **start**（或单击图表上写着 `start` 的地方）。转换实现：步 1 变为激活，其动作 **Pump** 显示对勾 ✓。
3. 关闭 **start**，然后打开 **full**：步 2 变为激活，**Valve** 打开。
4. 关闭 **full** 并打开 **empty**：grafcet 返回到步 0。
5. 单击右下角的**时序图**，查看每个信号随时间的变化。按 <kbd>Shift+F5</kbd> 停止。

如果储罐排空时 **start** 仍然保持打开，会发生什么？试一试：一旦步 0 再次激活，它的转换就会再次实现。这正是 GRAFCET 严格按照所绘内容运行的结果。使用上升沿 `↑start` 可以只对新的按下作出响应（输入 `^start`，请参阅[编写转换条件](expressions.md)）。

## 8. 保存 {#8-save}

每次更改后，您的工作都会自动保存在浏览器中。要得到一个可以保留、发送或纳入版本控制的文件，请按 <kbd>Ctrl+S</kbd>：项目将保存为 `<name>.grafcet.json`。双击顶部的项目名称可将其重命名。
