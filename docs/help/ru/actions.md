# Действия

Действия — это прямоугольники справа от шага. Они говорят, что система делает, пока шаг активен
или когда он становится активным. Выделите шаг и нажмите <kbd>A</kbd>, чтобы добавить действие;
нажмите <kbd>A</kbd> ещё раз на действии, чтобы добавить следующее. Выберите его **вид** кнопками с
рисунками на панели **Свойства**: каждая показывает, как диаграмма изображает этот вид.

## Непрерывные действия {#continuous-actions}

Самый распространённый вид. Текст — имя выхода (или внутренней переменной), например `Pump`. Выход
истинен, **пока** шаг активен, и становится ложным, как только им не управляет ни один активный
шаг.

Выберите вид **Условное**, чтобы добавить условие (_условие присваивания_): его поле появляется под
кнопками вида, и выход истинен, пока шаг активен **и** условие истинно. Условие изображается на
короткой линии над прямоугольником.

<!-- figure: continuous | Lamp, пока шаг 4 активен; Horn, только пока истинно и alarm -->

Таймеры в условии дают действия с задержкой и ограниченные по времени из других нотаций:

- `5s/X4` — с задержкой: выход включается через 5 с после активации шага 4.
- `/(5s/X4)` — ограниченное по времени: включено только в первые 5 с шага 4.

> **Примечание:** шаги, пройденные при неустойчивой эволюции (см.
> [Основы GRAFCET](grafcet-basics.md)), не выполняют свои непрерывные действия.

## Запоминаемые действия {#stored-actions}

Запоминаемое действие изменяет значение **один раз**, и значение сохраняется, пока его не изменит
другое действие. Его текст — присваивание: `C := C + 1`, `Motor := 0`, `Speed := 2.5`. Чтобы
установить переменную BOOL в TRUE, достаточно одного её имени: `Motor` означает `Motor := 1`.

- **При активации** — выполняется, когда шаг становится активным. Изображается стрелкой **↑ над**
  прямоугольником.
- **При деактивации** — выполняется, когда шаг становится неактивным. Изображается стрелкой **↓
  под** прямоугольником.
- **По событию** — выполняется каждый раз, когда наступает **событие**, пока шаг активен, например
  `↑reset`. Изображается **флажком** справа вверху, рядом с событием. Введите событие на панели
  «Свойства»; действие по событию без события никогда не выполняется и отмечается как проблема.

<!-- figure: stored | Запоминаемые при активации (↑), при деактивации (↓) и по событию (флажок) -->

У действий при активации и при деактивации тоже может быть условие: они выполняются, только если
оно истинно в этот момент.

Запоминаемые действия выполняются даже шагами, которые лишь пройдены при неустойчивой эволюции.
Используйте их для счёта, для фиксации значения (`Motor := 1` на одном шаге, `Motor := 0` на
другом) или чтобы запомнить, что что-то произошло.

## Команды принудительной установки {#forcing-orders}

Команда принудительной установки задаёт ситуацию другому частичному графсету, пока её шаг активен:
`G2{8}` активирует только шаг 8 графсета G2, `G2{*}` замораживает G2 в его текущей ситуации, `G2{}`
деактивирует все его шаги, а `G2{INIT}` возвращает его в начальную ситуацию. Она изображается
двойной рамкой. См. [Макрошаги, охватывающие шаги и принудительная установка](hierarchy.md).

## Действия без шага {#actions-without-a-step}

Действие не обязано принадлежать шагу. Когда ничего не выделено, нажмите <kbd>A</kbd> (или выберите
инструмент **Действие**) и щёлкните пустой холст: действие рисуется отдельно, без связи, и оно
**всегда активно**.

- Непрерывное действие без шага устанавливает свой выход всякий раз, когда истинно его **условие
  присваивания**, независимо от шагов: `Lamp` с условием `a * b` — это логика `Lamp = a · b`. Без
  условия выход всегда истинен.
- Запоминаемое действие по событию выполняется при каждом наступлении события, например
  `C := C + 1` по `↑pulse` считает импульсы. Действие при активации выполняется один раз при
  запуске моделирования. Действие при деактивации не выполняется никогда, так как действие никогда
  не деактивируется.

Перетащите любое действие, чтобы переместить его: на шаг, чтобы прикрепить его к нему (шаг
подсвечивается, а метка показывает место среди действий шага), или на пустой холст, чтобы оставить
его без шага.

## Несколько действий {#several-actions}

У шага может быть сколько угодно действий; они рисуются рядом. Перетащите действие вдоль ряда,
чтобы изменить их порядок, или используйте **Переместить действие влево / вправо** на панели
«Свойства», где выделенный шаг перечисляет свои действия компактными строками (щёлкните строку,
чтобы развернуть её). Удалите действие клавишей <kbd>Del</kbd>.

> **Внимание:** когда два шага, которые могут быть активны одновременно, управляют одним и тем же
> выходом непрерывными действиями, результат трудно читать. GrafcetMaker предупреждает об этом.
