# GrafcetMaker：免费的在线 GRAFCET 编辑器和仿真器

GrafcetMaker 在浏览器中绘制、检查和仿真 GRAFCET 图表（IEC 60848），并将其转换为 PLC 代码。它面向自动化工程师、教师和学生：免费开源（MIT 许可证），无需账户，并可离线使用。

GrafcetMaker 是一个网页应用：它可在任何启用了 JavaScript 的现代浏览器中运行。初次接触 GRAFCET？请阅读 [GRAFCET 指南](zh/guide/)，还有[英语](en/guide/)、[法语](fr/guide/)、[德语](de/guide/)、[西班牙语](es/guide/)、[丹麦语](da/guide/)、[瑞典语](sv/guide/)、[葡萄牙语](pt/guide/)、[波兰语](pl/guide/)、[俄语](ru/guide/)和[印地语](hi/guide/)版本。

## 致 AI 助手

ChatGPT 和 Claude 等 AI 助手可以为您绘制图表，并以链接的形式交给您，打开链接即可在此处查看。助手，请阅读 [ai.txt](ai.txt) 了解如何操作。在 GrafcetMaker 中，**文件 › 从文本打开…** 可打开助手编写的图表，**文件 › 复制为文本（供 AI 助手使用）** 可将您的图表交还给助手。

## 您可以用它做什么

- **绘制**：用鼠标或键盘绘制步、转换、转换条件和动作（<kbd>Enter</kbd> 继续一个序列），支持选择分支和并行分支、回路、源转换和阱转换以及注释。自动布局可按需整理图表。
- **检查**：在您绘图时检查图表：每个转换条件的语法和类型、未知变量、重复的步编号、不可达的步、死端、不互斥的选择、可能的瞬态循环以及由并行分支驱动的输出。大多数问题都有快速修复。
- **仿真**：按照 IEC 60848 演变规则进行仿真：激活步中的标记、已使能的转换、通过单击或输入更改的输入、定时器、边沿、不稳定步、grafcet 之间的强制、每个变量的时序图，以及可录制和回放的场景。
- **结构化**：用局部 grafcet、宏步及其展开、封装步和强制命令组织大型应用。
- **导出**：导出为 PDF（A4 或 A3，带标题栏，必要时分页平铺在多张纸上）、SVG、PNG 和 WebP，将变量表导出为 Excel 和 CSV，并生成结构化文本或 PLCopen XML。
- **协作**：通过链接实时协作：每个人都能实时看到其他人的指针和更改，并采用端到端加密。

## 支持的 GRAFCET 元素

| 元素 | GrafcetMaker 支持的内容                                                                   |
| ---- | ----------------------------------------------------------------------------------------- |
| 步   | 普通步和初始步、带展开的宏步、封装步；步变量 `X1`                                         |
| 转换 | 包含 AND、OR、NOT、上升沿 ↑ 和下降沿 ↓、`5s/X1` 等定时器以及数值比较的转换条件            |
| 结构 | 序列、选择分支和选择汇合、并行分支和并行汇合、回路、跳转、源转换和阱转换                  |
| 动作 | 连续动作、条件动作、激活时、停用时或事件触发的存储型动作；强制命令 `G2{8}`、`G2{*}`       |
| 变量 | BOOL、INT、REAL 和 TIME 类型的输入、输出和内部变量，带地址和注释                          |
| 记法 | 以普通 ASCII 输入（`a*/b`、`RE a`），以教科书记法（NOT 用上划线、↑ 和 ↓）或按输入原样显示 |

## 仿真

仿真器遵循 IEC 60848 的演变规则。初始步在启动时激活。当转换上方的所有步都激活时，转换被使能；当其转换条件也为真时，转换实现：下方的步变为激活，上方的步变为非激活。所有可实现的转换同时实现，同时被激活和停用的步保持激活。

每次输入变化后，仿真器都会寻求稳定：它不断实现转换，直到没有转换可以实现为止。途中被越过的步（不稳定步）不执行其连续动作，但其存储型动作会执行。时间是虚拟的，因此图表可以实时运行、加速运行或一次演变一步，并且时序图会记录每个变量。

| 格式               | 用途                                         | 打开方式                                                                                                                                                              |

结构化文本有两种风格：每个序列一个 `CASE`（与手写方式相同），或每个步一个 BOOL。生成的代码只是一个起点：在它于机器上运行之前，请对其进行检查。

## 常见问题

### GrafcetMaker 免费吗？有什么限制吗？

是的，它免费且基于 MIT 许可证开源。没有付费版本，没有试用期，也不限制项目、grafcet 或步的数量。

### 我需要注册或安装什么吗？

不需要。打开页面即可开始绘图；无需账户。您也可以从浏览器将其作为应用安装，像桌面程序一样启动它。

### 它可以离线使用吗？

可以。首次访问后，它所需的一切都存储在浏览器中，因此无需网络即可启动和工作。只有实时协作需要网络连接。

### 我的图表存储在哪里？

在您的计算机上。项目会自动保存在浏览器中，以及您保存的 `.grafcet.json` 文件中。不上传任何内容，应用也没有任何跟踪。实时会话采用端到端加密，密钥仅存在于链接中。

### 它可以在哪些浏览器和设备上运行？

Windows、macOS、Linux、平板电脑和手机上最新版本的 Chrome、Edge、Firefox 和 Safari。手机会使用适合小屏幕的布局，触摸屏则支持手势和更大的手柄。

### 它遵循哪个标准？

IEC 60848（在欧洲为 EN 60848）所定义的 GRAFCET。生成的代码遵循 IEC 61131-3。

### 它能打开其他 GRAFCET 软件的文件吗？

GrafcetMaker 可以打开 grafcet.io 文件（`.grafcetio`）并将其转换为项目。变量表可以从 Excel 和 CSV 导入。

### 我的公司可以在自己的网络上托管它吗？

可以。GrafcetMaker 是一组静态文件，任何网页服务器都可以在任意路径下提供它们，而且无需访问互联网。我们还提供了一个带 nginx 的 Docker 镜像。
