# शब्दावली

GRAFCET (IEC 60848) के मानक शब्द, जैसे GrafcetMaker में उपयोग होते हैं।

| शब्द                            | अर्थ                                                                                         |
| ------------------------------- | -------------------------------------------------------------------------------------------- |
| **एक्शन**                       | स्टेप के संबंध में सिस्टम क्या करता है; स्टेप के दाईं ओर एक आयत में बनाया जाता है।           |
| **सक्रिय स्टेप**                | वर्तमान स्थिति का हिस्सा बना स्टेप; सिम्युलेशन में उस पर एक टोकन होता है।                    |
| **AND कन्वर्जेंस**              | डबल लाइन जहाँ समानांतर शाखाएँ ख़त्म होती हैं; अगला ट्रांज़िशन उन सभी की प्रतीक्षा करता है।   |
| **AND डाइवर्जेंस**              | ट्रांज़िशन के बाद की डबल लाइन, जो कई स्टेप एक साथ सक्रिय करती है (समानांतर शाखाएँ)।          |
| **असाइनमेंट कंडीशन**            | कंटीन्यूअस एक्शन की कंडीशन: आउटपुट तभी तक सत्य है जब तक कंडीशन भी सत्य है।                   |
| **क्लियर होना (ट्रांज़िशन का)** | उसे पार करना: नीचे के स्टेप सक्रिय करना, ऊपर के स्टेप निष्क्रिय करना।                        |
| **क्लियर होने योग्य**           | सक्षम और सत्य रिसेप्टिविटी वाला: ट्रांज़िशन क्लियर होगा।                                     |
| **कंटीन्यूअस एक्शन**            | आउटपुट जो अपना स्टेप सक्रिय रहने तक (और उसकी कंडीशन सत्य रहने तक) सत्य रहता है।              |
| **एज**                          | किसी सिग्नल का तात्कालिक बदलाव: राइज़िंग एज ↑a (असत्य → सत्य), फ़ॉलिंग एज ↓a (सत्य → असत्य)। |
| **सक्षम ट्रांज़िशन**            | ऐसा ट्रांज़िशन जिसके ऊपर के सभी स्टेप सक्रिय हैं।                                            |
| **एनक्लोज़िंग स्टेप**           | स्टेप जिसमें एक एनक्लोज़्ड grafcet होता है, जो केवल स्टेप सक्रिय रहने तक चलता है।            |
| **इवेंट**                       | एज या कोई अन्य तात्कालिक कंडीशन, जो इवेंट पर स्टोर्ड एक्शन को ट्रिगर करती है।                |
| **एक्सपैंशन**                   | मैक्रो-स्टेप के लिए बनाया गया grafcet, उसके एंट्री स्टेप E से एग्ज़िट स्टेप S तक।            |
| **फ़ोर्सिंग ऑर्डर**             | एक्शन जो किसी दूसरे आंशिक grafcet पर एक स्थिति लागू करता है, जैसे `G2{8}`।                   |
| **प्रारंभिक स्टेप**             | शुरुआत में सक्रिय स्टेप; डबल वर्ग के रूप में बनाया जाता है।                                  |
| **मैक्रो-स्टेप**                | स्टेप जो अपनी अलग शीट पर बने एक्सपैंशन को दर्शाता है।                                        |
| **OR कन्वर्जेंस**               | सिंगल लाइन जहाँ वैकल्पिक शाखाएँ फिर से मिलती हैं।                                            |
| **OR डाइवर्जेंस**               | कई ट्रांज़िशन वाले स्टेप के बाद की सिंगल लाइन; एक ही रास्ता चुना जाता है।                    |
| **आंशिक grafcet**               | किसी प्रोजेक्ट के grafcet में से एक; सभी एक साथ चलते हैं।                                    |
| **रिसेप्टिविटी**                | ट्रांज़िशन के बगल में लिखी कंडीशन।                                                           |
| **स्थिरता की खोज**              | इनपुट बदलने के बाद विकास के नियमों को तब तक दोहराना जब तक कोई ट्रांज़िशन क्लियर न हो सके।    |
| **स्थिति**                      | किसी दिए गए क्षण में सक्रिय स्टेप का समूह।                                                   |
| **सोर्स / सिंक ट्रांज़िशन**     | ऐसा ट्रांज़िशन जिसके ऊपर / नीचे कोई स्टेप नहीं है।                                           |
| **स्टेप**                       | सिस्टम की एक स्थिर स्थिति; नंबर वाले वर्ग के रूप में बनाया जाता है।                          |
| **स्टेप वेरिएबल**               | `Xn`: स्टेप n सक्रिय रहने तक सत्य।                                                           |
| **स्टोर्ड एक्शन**               | एक बार चलने वाला एक्शन — एक्टिवेशन, डीएक्टिवेशन या किसी इवेंट पर — जिसका प्रभाव बना रहता है। |
| **टाइमर**                       | `t/c`: कंडीशन c सत्य होने के t समय बाद सत्य, जैसे `5s/X2`।                                   |
| **क्षणिक (अस्थिर) स्टेप**       | स्थिरता की एक ही खोज के दौरान सक्रिय और निष्क्रिय होने वाला स्टेप।                           |
| **ट्रांज़िशन**                  | स्टेप के बीच की बार; ट्रांज़िशन क्लियर होने से grafcet का विकास होता है।                     |
