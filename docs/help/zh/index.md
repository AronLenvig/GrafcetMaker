# 帮助中心

GrafcetMaker 让您直接在浏览器中绘制 GRAFCET 图表（IEC 60848）、检查图表并在仿真器中运行。这些页面将带您从第一个图表一直到高级功能。

## 初次使用 GrafcetMaker？ {#new-to-grafcetmaker}

- 从开始屏幕（**☰ › 开始屏幕和示例**）打开一个示例，按 <kbd>F5</kbd> 观看它运行。
- 参加导览（**帮助 › 开始导览**）：只需五步，您就能绘制第一个序列，为它添加一个动作并进行仿真。
- 使用右下角的旗帜选择语言。
- [入门](getting-started.md)：用大约十分钟绘制、检查并仿真一个小型储罐灌装图表。从这里开始。
- [GRAFCET 基础](grafcet-basics.md)：步、转换、转换条件、动作，以及使 grafcet 演变的五条规则。如果您还不熟悉 GRAFCET 本身，请阅读此页。
