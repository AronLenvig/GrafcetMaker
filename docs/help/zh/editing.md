# 编辑图表

GrafcetMaker 的设计让您很少需要手动放置任何东西：选中一个元素并按一个键，新元素就会自动编号、连线并定位。画布顶部工具栏下方的提示会列出适用于当前所选内容的按键。

## 基本按键 {#the-essential-keys}

| 按键                        | 选中步时                                     | 选中转换时                           |
| --------------------------- | -------------------------------------------- | ------------------------------------ |
| <kbd>Enter</kbd>            | 在下方添加一个转换和一个步，然后编辑转换条件 | 在下方添加一个步                     |
| <kbd>A</kbd>                | 添加动作                                     | —                                    |
| <kbd>P</kbd>                | 添加并行分支（AND）                          | 再添加一个它激活的步                 |
| <kbd>O</kbd>                | 添加选择分支（OR）                           | 添加一个可选转换（旁路）             |
| <kbd>L</kbd> 然后单击一个步 | 返回到该步                                   | 连线到该步（如果它尚未通向任何地方） |
| <kbd>F2</kbd> 或双击        | 编辑编号                                     | 编辑转换条件                         |
| <kbd>R</kbd>                | —                                            | 旋转：从上到下或从右到左             |
| <kbd>Del</kbd>              | 删除并重新连接序列                           | 删除                                 |

**从右到左**的转换是一条竖直横杠：来自它之前的步的连线从右侧进入，通往下一步的连线从左侧离开，并带有箭头。单击转换的横杠、编号或转换条件上的任意位置即可将其选中。

未选择任何内容时，<kbd>Enter</kbd> 会从序列的最后一个步继续该序列。在一个已经有后续的步上按 <kbd>Enter</kbd>，会插入新的转换和步，并将下方的所有内容下移。

编辑转换条件或动作时，<kbd>Shift+Enter</kbd> 会应用它并打开下一个：沿序列向下的下一个转换条件（在末尾新建一个转换和步），或该步的下一个动作（在最后一个之后新建一个）。这样可以一口气输入整个序列或一整行动作。

## 在图表上输入 {#typing-on-the-diagram}

<kbd>F2</kbd>、双击或 <kbd>Enter</kbd> 会在文本所在的位置直接打开它：像在画布上一样输入，周围的方框会随着输入而变大。<kbd>Enter</kbd> 应用（在注释中为 <kbd>Ctrl+Enter</kbd>），<kbd>Esc</kbd> 取消，单击其他地方也会应用。红色波浪下划线标出尚无效的值；文本下方的框会说明原因。

## 幽灵 {#ghosts}

选中的步会以虚线**幽灵**形式显示 <kbd>A</kbd> 和 <kbd>Enter</kbd> 将要添加的内容：在其最后一个动作之后的一个动作，以及在序列末尾的一个转换和一个步（带有它将获得的编号）。尚未通向任何地方的转换会显示一个幽灵步。单击幽灵即可添加；只单击幽灵转换的横杠则只添加该转换：它会被选中，接下来显示它自己的幽灵步。从幽灵添加的新步会被选中，就像您单击了它一样，因此它自己的幽灵只需再单击一次；稍后再输入转换条件（<kbd>F2</kbd> 或双击），或使用 <kbd>Enter</kbd> 边画边输入。使用放置工具时，指针下的幽灵会显示单击将放置的内容。

## 鼠标 {#mouse}

- **单击**进行选择；<kbd>Shift</kbd>+单击或 <kbd>Ctrl</kbd>+单击可将元素添加到所选内容或从中移除；在画布空白处拖动可框选（步会带上它的所有动作）；<kbd>Ctrl+A</kbd> 全选。所选元素之间的连线也会高亮。
- **拖动**任何选中的元素可移动整个所选内容（会对齐网格）；方向键可微移（按住 <kbd>Shift</kbd> 移动更大的距离）。
- **双击**元素可编辑其文本；双击画布空白处可在该处添加一个步。
- **右键单击**元素、所选内容或画布空白处，可查看能执行的操作（添加动作、分支、回路、编辑、设为宏步、剪切、复制、删除……；在空白处为在此处添加步、粘贴、自动布局、重新编号、适应窗口）。菜单键可为所选内容打开该菜单。
- 尚未写入转换条件的转换会显示一个灰色的 **?**（双击它或按 <kbd>F2</kbd>）；在您输入转换条件之前，问题列表仍会统计它。
- **连线手柄**：选中或悬停的步或转换会显示圆形手柄。拖动其中一个：只有有效的目标（步连到转换、转换连到步）会高亮。在画布空白处放下，即可在该处创建缺少的元素。
- 单击一条**连线**可将其选中；<kbd>Del</kbd> 只移除该连线。将向上的连线（回路）向侧面拖动可移动其侧边线，或将其底部线向上或向下拖动；双击它可恢复自动走线。自动走线时，回路会从其所在序列的步和连线下方经过，而不是穿过它们。
- 单击一条**双线**（并行分支或并行汇合）可将其选中：它会与它连接的连线一起高亮。拖动它或按方向键，可将其与转换一起移动；<kbd>Del</kbd> 移除这些连线，保留转换和步。

## 触摸：手机和平板 {#touch-phones-and-tablets}

- **轻点**进行选择。**拖动**元素可移动它；拖动画布空白处可平移；用两根手指**捏合**可缩放。
- **双击**元素可编辑其文本，双击画布空白处可在该处添加一个步。
- 在画布空白处**按住后拖动**，可框选框内的所有内容。
- 有所选内容时，画布底部的**工具栏**可完成电脑上按键所做的事情：**步**（在下方添加一个转换和一个步）、**动作**、**并行**和**选择**分支、**回路**、**编辑**、**详细信息**（属性）和**删除**。
- 选中的步或转换会在其正上方和正下方显示**连线手柄**：将其中一个拖到高亮的目标上，或拖到画布空白处以创建缺少的元素。
- 选择了某个工具（步、转换、注释、动作）后，在元素要放置的位置**轻点**。

在手机上，屏幕布局适合单手操作：工具、撤销和重做位于底部，菜单（☰）中包含文件、编辑、视图、仿真和帮助，面板（属性、变量、问题、仿真、时序图、大纲）通过右下角的面板按钮以覆盖在图表上的面板页形式打开。拖动面板页的手柄可使其变高或变矮。

## 工具 {#tools}

窗口顶部的工具栏包含各种工具（每个按钮中的字母是它的按键）：**选择**（<kbd>V</kbd>）、**平移**（<kbd>H</kbd>）、**步**（<kbd>S</kbd>）、**转换**（<kbd>T</kbd>）、**注释**（<kbd>C</kbd>）和**动作**（<kbd>Shift+A</kbd>）。使用放置工具时，单击画布空白处即可放置一个元素；按住 <kbd>Shift</kbd> 可放置多个。<kbd>Esc</kbd> 返回到选择工具。单击某个步时，动作工具还会为该步添加一个动作。

## 分支和结构 {#branches-and-structures}

分支和汇合永远不需要手动绘制；它们由连线自动得出。

- 在步上按 <kbd>O</kbd> 会添加另一个带有自己的步的输出转换：即**选择分支**。
- 在步上按 <kbd>P</kbd> 会添加一个与它并行的步，由同一个转换启动，并由下一个转换汇合：即**并行分支**和**并行汇合**。
- 将第二个步连线到一个转换会形成并行汇合；将第二个转换连线到一个步会形成选择汇合。
- **编辑 › 在步上方添加源转换 / 在步下方添加阱转换** 会添加一个上方或下方没有步的转换。

## 整理 {#tidy-up}

- **编辑 › 自动布局 grafcet** 将所有步按行排列，将分支居中放在其分支点下方，并将回路走线到侧边。**自动布局所选内容**只对所选内容执行此操作。布局永远不会自动进行，并且可以撤销。
- **编辑 › 重新编号步** 沿流向按顺序为步编号，并更新所有 `Xn` 引用和强制命令。

## 撤销、复制和粘贴 {#undo-copy-and-paste}

- <kbd>Ctrl+Z</kbd> 撤销，<kbd>Ctrl+Shift+Z</kbd> 或 <kbd>Ctrl+Y</kbd> 重做。一次完整的拖动是一个撤销步骤；编辑菜单会写明将要撤销的内容。
- <kbd>Ctrl+C</kbd>、<kbd>Ctrl+X</kbd>、<kbd>Ctrl+V</kbd> 可在 grafcet、项目和浏览器标签页之间使用。如果粘贴的步的编号已被占用，它们会被重新编号，并且它们使用的变量也会一起带过来。

## 导航 {#navigate}

- 滚动可平移；<kbd>Ctrl</kbd>+滚动或捏合可缩放；<kbd>Space</kbd>+拖动、按住鼠标中键或右键也可以平移（不移动的右键单击仍会打开菜单）。
- <kbd>Shift+1</kbd> 适应整个 grafcet，<kbd>Shift+2</kbd> 适应所选内容，<kbd>Shift+0</kbd> 为 100 %。
- <kbd>Ctrl+K</kbd> 打开命令面板：输入任何命令或 grafcet 名称。

## 注释和名称 {#comments-and-names}

- 注释（<kbd>C</kbd> 工具）是图表上的自由备注；仿真器会忽略它们。
- 步标签（属性面板）是显示在步左侧的简短描述。
- 双击顶部的项目名称可重命名项目，双击 grafcet 标签页可重命名该 grafcet。

## 同时显示两个 grafcet {#two-grafcets-at-once}

按 <kbd>Ctrl+\</kbd>（或 **视图 › 分屏**）可在第一个 grafcet 旁边显示第二个 grafcet，也可以右键单击标签页并选择**在侧边打开**或**在下方打开**。每个窗格顶部都有自己的 grafcet 选择器。在某个窗格中单击即可在其中工作：它的标题会高亮，标签页、键盘和属性面板都跟随它。拖动窗格之间的横条可调整其大小；× 关闭一个窗格。

## 属性和面板 {#properties-and-panels}

图表占据整个窗口；其余内容浮在它上面，需要时才显示。选中某个元素，它的**属性**就会出现在左侧的卡片中：步或动作的类型通过显示其符号的图片按钮来选择。卡片上的 × 会为此次选择隐藏它；未选择任何内容时，项目名称旁边的属性按钮会显示 grafcet 和项目。**变量**、**问题**、**时序图**和**大纲**面板通过右下角的按钮打开，显示在右侧的卡片中，您可以拖动其左边缘将其加宽。仿真期间，仿真面板（输入、值、日志、场景）浮在左侧。

选中多个元素时，卡片会给出概览：有多少个步、转换、动作和注释（单击其中一项可只保留这些），以及按阅读顺序排列的所选内容树，每个步下面列出它被选中的动作和转换（仅因它们而显示的步以斜体表示）。单击某一行可只选择该元素；<kbd>Ctrl</kbd>+单击可将其从所选内容中移除。
